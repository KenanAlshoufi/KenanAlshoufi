## 👨‍💻 About Me

I'm **Kenan Alshoufi**, a .NET Backend Developer passionate about software engineering, backend development, and application security.

I focus on building backend applications using C# and ASP.NET Core, designing relational databases, implementing authentication mechanisms, and applying structured software architecture.

- 🚀 Developing RESTful APIs with ASP.NET Core.
- 🏗️ Applying 3-Tier Architecture and Dependency Injection.
- 🗄️ Working with SQL Server, T-SQL, and Data Access Technologies.
- 🔐 Exploring Cryptography and Application Security.
- ⚙️ Building Windows Services and Background Worker Services.
- 🧠 Continuously improving my problem-solving and engineering skills.
